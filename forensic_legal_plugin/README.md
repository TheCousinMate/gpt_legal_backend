
# Forensic Legal Cognition 4.1 – Plugin GPT Legal

Este plugin permite acceder a un backend jurídico especializado en análisis normativo, doctrinal y forense. 

### Funcionalidades
- Reflexión jurídica y doctrinal
- Interpretación normativa
- Predicción de riesgo jurídico
- Análisis forense automatizado
- Consulta normativa en línea (Chile)

### Cómo usar
1. Instala desde el explorador de plugins de ChatGPT usando el archivo `ai-plugin.json`.
2. Asegúrate de que tu clave de OpenAI esté activa.
3. Accede a `https://gpt-legal-backend.onrender.com/docs` para probar los endpoints.
